# Mobile remote threat model

Phase 12 ships no network listener and the prototype flag is false. A future local companion would need private-interface binding, authenticated encrypted pairing, short-lived codes, per-device revocable keys, replay protection, rate limits, version negotiation, restricted-content filtering, visible connections, emergency disable, firewall guidance, and no arbitrary commands, paths, diagnostics, default power actions, UPnP, or public bind. Until independently reviewed and tested, documentation is the only approved result.
