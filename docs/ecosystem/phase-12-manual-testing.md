# Phase 12 manual testing

Use synthetic/non-sensitive content. Verify one game/application start and end; timeline privacy, filters, deletion, retention, and redacted local export; direct-action PNG/JPEG capture, cancellation/failure, collision, cursor, approved Gallery indexing, Snipping Tool, hotkey opt-in/conflict/Safe Mode; externally completed recording discovery without source modification; media controls and Guest clearing; manually configured remote-client launch/restore; honest integration capability labels.

Never automate screenshot or recording tests. A human must deliberately invoke each capture in the current session. Record hardware, display topology, client versions, measurements, and unavailable integrations without claiming unperformed coverage.
