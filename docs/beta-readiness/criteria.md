# Beta readiness criteria

Beta Candidate requires verified data safety/migrations/recovery, stable startup/sign-in, signed clean install/update/uninstall, representative Steam/manual/Windows/PWA/emulator launching, controller and keyboard navigation without traps, acceptable low-end/idle/memory/large-library results, usable High Contrast/Reduced Motion/200% scaling, primary accessible names, complete feedback workflow, and tracked blockers.

Automated tests alone cannot satisfy hardware, packaging, accessibility, or soak criteria.

## Phase 12 ecosystem gate

Beta additionally requires hardware/manual proof that capture happens only after a current-session direct action; opt-in hotkeys conflict/unregister safely and remain off in Safe Mode; capture/recording files are never created by automatic triggers; privacy/export redaction holds; external recording files stay untouched; media controls remain stable; remote-client launch/restoration works without credentials; unsupported achievement/download capabilities remain honest; no mobile listener exists; and idle/performance measurements are recorded on representative systems.

## Phase 13 gate

Beta requires real-file playback validation across declared formats, subtitle/audio-track samples, repeat-play memory measurements, controller-family testing, installed-package testing, external-player testing, supported-emulator fixture coverage, and completion of the inactive installed-app/Start Menu emulator sources. Public distribution also requires documented redistribution permission for the supplied PlayStation assets.

Beta additionally requires correct adaptive prompts on representative controller families, couch-complete OSK and recovery flows, conflict-safe remapping/recovery, Guest metadata suppression, preferred-display fallback, TV calibration, touch/handheld verification, and a signed installable package.
