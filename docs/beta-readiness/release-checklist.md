# Beta release checklist

- [ ] No untriaged Critical/High alpha issues.
- [ ] Supported migration/update/rollback matrix passes.
- [ ] Signed x64 package clean install/update/repair/uninstall passes without Developer Mode.
- [ ] Representative launch/tracking/restoration matrices pass.
- [ ] Controller, keyboard, mouse, scaling, High Contrast, Reduced Motion, and screen reader runs pass.
- [ ] Four-hour idle, two-hour navigation, 100-launch, and large-library measurements pass.
- [ ] Compatibility contribution validation and maintainer reviews operate publicly.
- [ ] Owner-approved license, signing identity, release URLs, hashes, notes, and known issues are published.
