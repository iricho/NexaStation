# Phase 7 manual testing

## Layout and focus

1. Start with each layout selected; verify one visible layout tree and no startup exception.
2. Navigate every section with keyboard/controller, open Quick Menu, launch and close an app, and verify semantic focus returns.
3. Switch Modern → Crossbar → Handheld and verify the section/target is preserved or a nearby safe card receives focus.
4. At 1280×720 verify Handheld content remains readable and reachable.

## Customization and persistence

1. Reorder, disable, resize, and restyle dashboard rows; restart and verify persistence and at least one safe row.
2. Pin targets, reorder pins, disconnect a target, and verify the unavailable reference is retained.
3. Create manual, folder, nested, mixed, and smart collections; verify cycle/depth/rule validation and bounded results.
4. Preview/cancel/apply all themes, sound packs, reduced motion, and Minimal/Balanced/Cinematic presets.

## Import, recovery, and safety

1. Export, preview, and import a valid configuration; verify a backup and unchanged library/provider/Gallery records.
2. Reject unsupported versions, scripts, URLs, traversal, and unknown enum values without partial state.
3. Press Ctrl+Shift+R, cancel once, then confirm; verify backup-first safe defaults and retained content.
4. Verify original applications, game files, emulator configuration, Gallery media, and artwork are never modified.

Record hardware, Windows build, build configuration, item/collection/pin scale, timings, working set, CPU/GPU observations, and any fallback. Do not infer or invent measurements.
