# Media Hub

The Media page organizes existing local-library and Gallery data without duplicating source records. Its rows are **Recently Opened**, **Streaming Applications**, **Video Apps**, **Music Apps**, **Local Videos**, **Gallery Recordings**, **Favorites**, **Media Servers**, and **All Media Apps**.

Application classification reuses Phase 4 categories: Media, Streaming, Entertainment, Music, and Video. User-edited categories remain authoritative. Media-server entries are ordinary imported applications; Phase 6 does not connect directly to Plex, Jellyfin, Kodi, or other servers.

Recently Opened is launch history, not playback progress. NexaStation does not label it “Continue Watching,” because Phase 6 has no reliable playback-position model. Private Gallery sources are excluded outside Gallery, while missing media remains in history as unavailable.
