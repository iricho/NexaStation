# Reporting bugs

Use **Settings → Report a Problem**. Enter category, expected/actual behavior, reproduction steps, and Safe Mode result. NexaStation can save a local ZIP and copy a redacted Markdown template. The browser opens only after a second explicit action; issue creation and attachment remain manual.

Do not upload ROMs, games, photos, credentials, private paths, full databases, or unreviewed bundles. The repository currently has no configured issue URL.
