# Alpha triage process

Severity is Critical, High, Medium, or Low. Categories cover startup, packaging, updates, database, providers, navigation, controller, display/audio/network, artwork, accessibility, performance, recovery, and security.

States flow from Needs Triage through information/reproduction/confirmation/fix/verification. Fixed requires an identified cause, a fix, regression coverage where practical, manual verification of the original scenario, and related-system regression verification. Release Blocker is explicit and cannot be closed by relabeling.
