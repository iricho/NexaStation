# My Stuff

My Stuff is the personal hub shared by the Modern and Classic Crossbar layouts. It is hidden in Guest Mode and keeps these sections in a stable order: Personal Shelves, Game Progress, Video Queue, Favorites, Recently Added, and Automatic Shelves.

Game progress uses Backlog, Playing, Completed, and Dropped. A successful game launch changes Unassigned or Backlog to Playing, but never overwrites Playing, Completed, or Dropped. Video Queue presents the same stored values as Watch Later, Watching, Watched, and Dropped. Native Gallery playback marks a video Watching when playback starts and Watched only after a natural end; external players never infer completion.

Unassigned is represented by the absence of a lifecycle row, so existing and newly imported content remains untouched. Statuses are keyed by typed library or Gallery IDs and stay outside interface export/import.

Opening any Shelf or status section shows a searchable full grid. Returning restores focus to the originating Shelf card. Personal Shelves keep explicit order and allow one-item add, remove, move-earlier, and move-later actions. Dynamic Shelves are read-only views whose membership follows validated rules.
