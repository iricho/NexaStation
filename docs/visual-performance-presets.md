# Visual performance presets

Minimal disables blur, shadows, animated backgrounds, and focus motion while lowering decode/cache budgets. Balanced is the default bounded visual profile. Cinematic enables higher artwork quality and animation while retaining pause-on-inactive, pause-during-launch, and battery-reduction policies. Any manual change is stored as Custom.

Reduced motion overrides animation and background transitions in every preset. Per-row item limits, smart query caps, artwork memory/disk budgets, and inactive-layout collapsing prevent customization from creating unbounded work.
