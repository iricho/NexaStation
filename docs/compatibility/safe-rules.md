# Safe compatibility rules

Allowed rules select a launch target/working directory, add adapter-approved arguments, adjust bounded timeouts, keep the frontend visible, select a typed tracking strategy, identify/ignore process names, adjust restoration timing, choose safe controller navigation behavior, reduce artwork work, or defer provider refresh.

Commands, scripts, PowerShell, Registry changes, deletion/moving, process killing, injection, drivers, elevation, security changes, executable downloads, and arbitrary environment extraction are rejected. Compatibility processing never modifies external application, Steam, emulator, game, or media files.
