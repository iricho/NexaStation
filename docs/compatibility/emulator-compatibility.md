# Emulator compatibility

Profiles match a platform/adapter pair and may include adapter version constraints. Actual probe results remain authoritative when they conflict with built-in assumptions. Profiles cannot change emulator configuration, download software, or include game content.

Dolphin, PCSX2, PPSSPP, RetroArch, experimental RPCS3, and custom adapters still require real-version matrix testing with legally obtained demos/homebrew.
