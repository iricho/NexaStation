# Artwork troubleshooting

- **Provider unavailable:** save the required key, enable online artwork, then test the provider.
- **No match:** verify title/platform or place an exact `Title-cover.png`/`Title-hero.png` file in the local import folder.
- **Several matches:** leave the item in review; do not lower the threshold just to force a result.
- **Rejected image:** verify HTTPS, supported MIME/signature, complete PNG/JPEG data, size, and dimensions.
- **Job offline:** reconnect and explicitly resume it.
