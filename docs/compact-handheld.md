# Compact Handheld

Compact Handheld targets Windows handhelds and 720p-class displays. It uses a tab-like section strip, a compact primary grid, reduced margins, touch-friendly sizing, and bounded artwork decoding.

The presentation is not a separate library. Favorites, recent activity, providers, manual items, Gallery, collections, themes, and launch state are shared with the other layouts. Card presentation resolves compact dimensions while preserving missing, favorite, progress, and provider semantics.

Reduced motion removes focus animation. The layout keeps controller, keyboard, mouse, and touch navigation available without installing global hooks or intercepting input while another application is foreground.
