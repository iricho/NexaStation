# Native player manual test checklist

Use owned, non-DRM local samples. Verify play, pause, stop, seek limits, volume, mute, each speed and aspect mode, fullscreen round-trip, focus restoration, resume/start-over/forget, queue boundaries, embedded and sidecar tracks, an unsupported file, Open With, and Private title handling. Record the exact containers, codecs, controllers, subtitle files, external players, latency, and memory measurements actually tested.
