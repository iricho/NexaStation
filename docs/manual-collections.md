# Personal Shelves

Personal Shelves contain ordered typed references, including games, applications, media shortcuts, Gallery photos and videos, albums, and nested Shelves. Creating, renaming, adding, removing, and reordering updates only NexaStation's Shelf references; source applications, ROMs, media, albums, and files remain untouched.

Shelves can be nested to five levels. Self-reference and recursive item graphs are rejected before persistence. Shelf Groups provide hierarchy, personal Shelves can be pinned, and either personal or Dynamic Shelves can become a bounded Home row. The internal database names remain unchanged for compatibility.

Mixed target types retain their type discriminator so an ID from one subsystem cannot be mistaken for another.
