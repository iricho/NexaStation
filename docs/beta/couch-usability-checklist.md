# Couch usability checklist

- Complete onboarding, dashboard navigation, search, OSK, details, Quick Menu, Guest entry/exit, display calibration, and recovery with each supported controller family.
- Verify adaptive prompts, safe back, focus visibility/restoration, disconnect fallback, repeat/deadzone behavior, touch targets, RTL input, and 720p/1080p/4K layouts.
- Confirm restricted content never reveals metadata and destructive/system actions remain gated.
