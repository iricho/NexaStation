# Beta release checklist

- Zero-warning x64 Release build and full automated suite.
- Signed MSIX install/update/uninstall on clean Windows machines.
- Representative Xbox, PlayStation, Nintendo-style, generic, handheld, touch, TV, HDR, high-contrast, and multi-monitor manual runs.
- Privacy/security review, dependency/license approval, startup/memory/soak budgets, and no open Critical/High defects.
