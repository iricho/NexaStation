# Application categorization

Phase 4 seeds Entertainment, Media, Communication, Browser, Streaming, Utilities, System, Productivity, Development, Creative, Files, Remote Access, and Uncategorized. Conservative local rules use display name, Start Menu folder, publisher/category hints, target name, and PWA evidence.

Classification distinguishes applications, related tools, uninstallers, documentation, web shortcuts, and unknown entries. Only launchable candidates with sufficient confidence are recommended. An automatic category can be changed in application details. A user category is authoritative: refresh may update provider categories but cannot replace a user primary category.

Apps are grouped by primary category. Card styles are persisted per item and cycle through Wide, Square, Compact, and Icon without changing source metadata or launch targets.
