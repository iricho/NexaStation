# GOG

GOG discovery conservatively recognizes standard uninstall entries whose publisher identifies GOG and retains the installation as a read-only source. Galaxy URIs are alternate launch targets when an ID is available. Standalone DRM-free executables are not guessed or rewritten; manual items remain supported.

When online artwork is allowed, newly imported GOG games automatically queue missing covers and heroes. Numeric GOG product IDs use GOG's public catalogue directly, without an API key. Existing user-selected artwork is never replaced, and artwork failure never rolls back the game import.
