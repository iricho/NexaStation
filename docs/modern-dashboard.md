# Modern Dashboard

Modern Dashboard is the default TV-oriented layout. It projects persisted, ordered dashboard rows with optional titles, item limits, card style, card size, badges, progress, and empty-state policy. Built-in defaults include pins, recent activity, applications, favorites, recently added content, games, and media.

Rows may also point to manual or smart collections by stable collection ID. Queries are bounded and missing sources produce an empty/safe row instead of a startup failure. At least one navigable row must remain enabled.

Only this layout tree is visible while Modern Dashboard owns input. Gallery, Media Hub, Quick Menu, and Settings remain shared surfaces rather than duplicated data stores.
