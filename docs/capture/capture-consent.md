# Capture consent

## Mandatory rule

NexaStation never captures a screenshot automatically and never starts recording. A screenshot can be created only by a direct, intentional user action in the current session. Each action issues one action-bound token valid for 15 seconds and consumed once. First use explains the behavior.

System/Snipping selection stays visible. Secure-desktop and protected-content restrictions are not bypassed. A target is not retained beyond the action. Detecting a new file in an explicitly approved recording folder means only that an external application created it; NexaStation never claims authorship.
