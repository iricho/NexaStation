# Capture troubleshooting

- **Consent required:** invoke Capture Screenshot again; tokens cannot be reused.
- **Unavailable/protected:** use the visible Snipping Tool and respect Windows/content restrictions.
- **Hotkey conflict:** choose a different shortcut or keep global capture disabled.
- **No Gallery item:** approve the exact destination as an enabled Gallery source.
- **No recording found:** approve the recorder output folder and wait until the external app finishes the file.

Failures create neither captured-media nor successful activity records.
