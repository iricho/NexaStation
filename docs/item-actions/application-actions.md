# Application actions

Applications expose Open, Details, Edit, Favorite, Hide/Unhide, collections, safe location navigation, and management where supported. Management opens Steam or Windows Installed Apps after confirmation. NexaStation never invokes an uninstall string, MSI command, shell, elevation request, PowerShell, or third-party remover.

Removing an application deletes only its NexaStation index/history records. A later provider scan may rediscover an application that remains installed.
