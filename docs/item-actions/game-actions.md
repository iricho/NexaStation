# Game actions

Games expose Play/Open, Details, Edit, Favorite, Hide/Unhide, Add to Shelf, progress status, artwork actions, compatibility reporting, safe local-folder navigation, provider navigation, installation management, and Remove from NexaStation when the relevant capability exists.

Emulated games use the same surface. Their location is the indexed game path, and removal never deletes the ROM, disc image, emulator, save files, or artwork originals. Provider-specific actions appear only when a structured provider identity is available.
