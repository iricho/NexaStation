# Remove versus uninstall

**Remove from NexaStation** changes only NexaStation's local database. It does not uninstall an application, delete a game installation, delete a ROM, delete an emulator, delete original artwork, or delete Gallery source media.

**Manage installation** opens the original provider when a safe structured URI exists; otherwise it opens Windows Installed Apps. The user remains in control of any provider/Windows steps. NexaStation does not monitor, automate, or assume the result. Items remain indexed until a later explicit refresh reports a changed state.

Provider-owned entries may be rediscovered on a later scan. Hide is the reversible choice when the user wants to retain metadata while excluding an item from normal views.
